## MybatisX-ext idea 快速开发插件

Fork from [MybatisX](https://gitee.com/baomidou/MybatisX)
添加了 sql 拼接日志輸出支持

> 为免安装插件后与 MybatisX 在仓库中版本不一致，收到更新提醒，修改了group、version和插件名

MybatisX-ext is an enhanced version of MyBatisX, providing additional support for log concatenation and improved SQL debugging.
This project is independently maintained and forked from MyBatisX, but it is not affiliated with or endorsed by the official MyBatisX project.

MybatisX-ext is licensed under the GPL-2.0 License because it includes code from mybatis-log-plugin-free (licensed under GPL-2.0).

使用文档：https://baomidou.com/pages/ba5b24/

MybatisX-ext 辅助 idea 快速开发 mybatis 插件，为效率而生。

Jar 安装： File -> Settings -> Plugins -> Install plugin from disk.. 选中 zip包 安装
